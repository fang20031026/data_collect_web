Camera Collector Windows 使用说明

1. 解压 release\camera_collector_windows.zip。
2. 进入解压后的 camera_collector_windows 文件夹。
3. 双击 camera_collector.exe 启动程序。
4. 程序会自动启动本地服务，并自动打开浏览器页面。
5. 点击“选择保存目录”，选择你的采集保存位置。
6. 选择采集模式：单摄像头 或 多摄像头。
7. 打开摄像头后，点击“开始录制”；结束时点击“停止录制”。

单摄像头模式

1. 选择一个摄像头并打开。
2. 停止录制后会保存为 MP4。
3. 文件名按 6 位编号递增：000000.mp4、000001.mp4、000002.mp4。
4. 文件直接保存在你选择的保存目录下。

多摄像头模式

1. 分别设置 head、left、right 三路摄像头。
2. 三路都打开后才能开始录制。
3. 三路可以选择同一个摄像头，也可以选择不同摄像头。
4. 三路打开后，修改某一路下拉框时，只会切换该路。
5. 停止录制后会保存为 MP4 + JSON，目录结构如下：

选择目录/
├── head/000000.mp4
├── left/000000.mp4
├── right/000000.mp4
└── metadata/000000.json

说明

1. head / left / right 每次保存会使用同一个 6 位编号。
2. 如果浏览器弹出摄像头权限请求，请点击“允许”。
3. 如果 Windows 防火墙弹窗，请允许本地访问（localhost / 127.0.0.1）。
4. 发布包内已包含 ffmpeg，无需额外安装 Python 或 ffmpeg。
