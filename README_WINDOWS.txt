Camera Collector Windows 使用说明

1. 双击 camera_collector.exe。
2. 程序会自动启动本地服务，并打开浏览器页面。
3. 点击“选择保存目录”。
4. 选择“单摄像头”或“多摄像头”模式。
5. 单摄像头模式：选择设备，点击“打开摄像头”。
6. 多摄像头模式：为 head、left、right 选择摄像头，点击“打开全部摄像头”。
   - head 输出固定为 1280 x 720。
   - left 输出固定为 640 x 360。
   - right 输出固定为 640 x 360。
   - 三路都打开后才能开始录制。
   - 三路可以选择同一个摄像头，也可以选择不同摄像头。
   - 三路打开后，修改某一路的摄像头下拉框会只切换该路。
7. 浏览器请求权限时选择允许。
8. 点击“开始录制”。
9. 点击“停止录制”。
10. 自动保存开启时，单摄像头 MP4 会保存为 000000.mp4、000001.mp4、000002.mp4。
11. 多摄像头模式会保存为：

   选择目录/head/000000.mp4
   选择目录/left/000000.mp4
   选择目录/right/000000.mp4
   选择目录/metadata/000000.json

12. 切换到新的保存目录后，编号会从 000000.mp4 重新开始。
13. 点击“退出程序”关闭本地服务。

推荐浏览器：Chrome、Edge 或 Firefox 最新版。

如果提示 ffmpeg 不可用：
- 请确认发布包内已包含 ffmpeg；
- 或将 ffmpeg.exe 加入 Windows PATH。
